# APC Physique Chimie App

Offline-first Flutter app for Togolese Physics & Chemistry high-school students at Lycée de Vogan, using the Approche Par Compétences (APC). It provides contextualized problem situations, chapters, and teacher mode for low-connectivity classroom use.

## Stack
Clean Architecture, Riverpod, Hooks Riverpod, Fpdart, Hive, Hive Flutter, Path Provider, GoogleFonts Abel, and Flutter Secure Storage.

## Style Carré
All UI follows Style Carré: 0.0 radius, 0.0 elevation, GoogleFonts Abel, `#263238` background, `#4CAF50` accent, and `#37474F` surface.

## Setup
```bash
flutter pub get
flutter pub run build_runner build --delete-conflicting-outputs
flutter run
```
